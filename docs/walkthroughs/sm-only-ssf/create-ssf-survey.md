# Create SSF Survey

## Purpose

Create the survey cycle with Singapore Skills Framework context and one cycle-level custom competency.

## Steps

1. Open `/tenant/survey-cycles`.
2. Create `East West Leadership 360`.
3. Use the goal `Assess leadership behaviours for branch managers and create practical development feedback.`
4. Choose job family `Leadership & Strategy` and seniority `Director, Vice President`.
5. Keep the framework as `Critical Core Skills (SSF)`.
6. Select at least `Decision Making` and `Developing People`.
7. Add custom CCS competency `Digital Transformation Leadership`.

## Expected result

The cycle details show the SSF framework, selected SSF competencies, and the custom competency context.
