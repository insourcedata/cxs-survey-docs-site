# SM-only SSF Walkthrough

## Purpose

Run a streamlined local demo where the platform admin provisions the tenant, then Senior Management performs every tenant action.

## Steps

1. Use Singapore Skills Framework Critical Core Skills.
2. Add one cycle-level custom CCS competency.
3. Do not invite HR, sign in as HR, or create a tenant custom framework.
4. Complete the flow through report generation.

## Expected result

Senior Management can import employees, create the SSF survey, review AI wording, approve, assign raters, monitor completion, and generate the final report.
