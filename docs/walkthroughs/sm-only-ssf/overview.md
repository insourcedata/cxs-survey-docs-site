# SM-only SSF Walkthrough

## Purpose

Show how Senior Management can run a complete leadership feedback cycle without switching to an HR user.

## Steps

1. Start with an empty organization workspace.
2. Add the people who will participate in the review.
3. Create a leadership survey using Critical Core Skills.
4. Add one organization-specific competency for digital transformation leadership.
5. Review the AI-assisted questionnaire before approving it.
6. Invite raters, monitor completion, and generate the final report.

![Senior Management workspace overview](/img/walkthroughs/sm-only-ssf/07-survey-cycles-empty.png)

## Expected result

Senior Management sees one guided workspace for survey setup, approval, rater invitations, completion tracking, and reporting.
