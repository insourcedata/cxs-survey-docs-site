# Walkthroughs

## Purpose

Use these pages to understand how Survey360 supports a leadership 360 review from setup to final insight.

## Steps

1. Start with the scenario that matches your business conversation.
2. Move through the pages in order.
3. Use the screenshots to see what the user interface looks like at each stage.

## Expected result

You should finish with a clear picture of the user journey, the decisions Senior Management makes, and the outputs they can expect.
